# Project Rules & Guidelines

## 🚨 CRITICAL CONTENT PROTECTION RULES

This project contains a complete Learning Management System with manually created courses, modules, lessons, resources, quizzes, assignments, progress tracking, and syllabus data.

### ⚠️ ABSOLUTE RULES
- **DO NOT** modify, regenerate, replace, delete, rename, reorder, merge, or restructure ANY existing educational content.
- The following MUST remain strictly untouched:
  - Course Names & Course IDs
  - Module Names, Order, Content & IDs
  - Lesson Names, Order, Content & IDs
  - Resource Names, Files (PDFs, Videos, Labs, Workbooks, Links)
  - Quiz & Assignment Structures
  - Syllabus & Learning Roadmaps
  - Progress Tracking, XP System, Completion Logic & Saved Positions
  - Certificates & Learning Analytics
  - Database Schema & API Responses

### ✅ ONLY IMPROVE PRESENTATION / VISUAL DESIGN
You are strictly limited to enhancing visual appearance and UX without altering underlying data:
- UI Design, Colors, Typography, Spacing, Padding, Margins
- Cards, Shadows, Glassmorphism, Micro-animations, Hover Effects
- Icons, Progress Rings, Animated Progress Bars
- Badges (Difficulty, Estimated Time, Completion Status)
- Layout Responsiveness & Accessibility
- Buttons, Loading Skeleton States, Theme Styling
